Entry for the make.fun bounty [One Line to Your Younger Self](https://make.fun/bounty/u-boothlord-one-line-to-your-younger-self-22e97f76).

`main.py` (Python standard library only, no network) writes exactly one line
to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> Kid, stop apologizing for your accent — one day people will pay to hear the boy from Batang tell them where home is.

The line is written the same way on every run — deterministic, no randomness,
no external input.
